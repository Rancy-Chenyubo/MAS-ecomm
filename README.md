# MAS-ecomm

基于多智能体仿真的电商平台佣金与补贴策略研究。项目构建平台、商家、达人和用户四类主体，通过单平台与双平台实验，探索佣金、补贴如何影响交易规模、平台收益与生态稳定性。

## 项目概述

- **研究问题**：平台如何在规模增长、收益回收和多方利益之间选择佣金与补贴策略？
- **建模方式**：结合大语言模型驱动的智能体决策、历史记忆与规则化交易结算，模拟主体之间的连续互动。
- **平台类型**：内容驱动型电商平台与搜索货架型电商平台。
- **观察指标**：GMV、平台收益（佣金收入 + 广告收入 − 补贴支出）、商家利润与退出情况、用户购买行为、达人流向及带货贡献。

## 仿真框架

| 主体 | 主要行为 |
| --- | --- |
| 平台 | 设置佣金与补贴；动态实验中根据市场反馈调整策略 |
| 商家 | 商品定价、广告投放、平台选择与退出 |
| 达人 | 选择合作商家及平台，参与带货与佣金分配 |
| 用户 | 根据价格、补贴、偏好与达人推荐做出购买选择 |

各主体结合当前环境与历史记忆做出决策，再由交易及收益核算规则生成本轮结果，并反馈到下一轮。

## 实验设计

| 文件 | 实验 | 主要内容 |
| --- | --- | --- |
| `test1.1.ipynb` | 单平台静态实验 | 固定佣金与补贴组合，比较平台内部的收益、交易和主体行为 |
| `test2.1.ipynb` | 双平台静态竞争 | 设计 16 组高低佣金与补贴组合，观察市场份额与主体流向 |
| `test3.1.ipynb` | 双平台动态博弈 | 从不同初始策略出发，由平台自主调整政策，观察策略演化与稳定过程 |

## 主要发现

- **规模增长与收益增长并不同步**：补贴可以促进交易，但补贴成本也可能抵消规模带来的收益。
- **策略效果依赖多方反馈**：佣金与补贴通过商家定价、用户购买和达人合作共同影响市场结果。
- **动态稳定不等于静态最优**：初始策略与竞争路径会影响最终状态，不同起点可能形成不同的局部稳定结果。

上述发现来自设定条件下的仿真实验，仍需结合真实市场数据进一步校准与验证。

## 使用说明

代码以 Google Colab 环境编写，默认模型为 `Qwen/Qwen2.5-14B-Instruct`，主要依赖 PyTorch、Transformers、Accelerate 和 pandas。

1. 在 Colab 中打开对应笔记本，选择能够加载模型的 GPU 运行环境，并安装所需依赖。
2. 挂载 Google Drive，按需修改 `BASE_DIR`、模型路径及输出目录。
3. 检查策略组合与轮数配置后，按顺序运行单元格。
4. 在结果目录查看轮次汇总、主体明细与交易记录；动态实验还会保存平台策略轨迹。

**当前代码配置**：实验一运行 6 组组合，每组 5 轮；实验二默认运行 16 组中的中间 14 组，完整运行需将 `STRATEGY_COMBOS` 设为 `ALL_COMBOS`；实验三包含 4 组初始策略，最多运行 10 轮，并设有提前停止条件。请以实际配置为准，部分注释和进度提示保留了早期实验的组数。

本地运行时需移除 Colab 专用的 Drive 挂载代码并调整路径。模型权重需自行下载；模型采样具有随机性，结果可能随运行环境和生成过程变化。
